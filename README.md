GS Produção - Landing Page Institucional

🚀 Sobre o Projeto
Página de apresentação institucional com informações de serviços, galeria de projetos, localização e contato integrado via WhatsApp.

HTML5
CSS3 (Design System com paleta executiva cinza)
JavaScript Vanilla (Interatividade e integração WhatsApp)

Hero Section: Apresentação principal com imagem de destaque e acesso rápido aos serviços.
Quem Somos: Apresentação institucional e diferenciais.
Áreas de Atuação: Lista detalhada de serviços prestados.
Galeria de Projetos: Registros visuais das produções e eventos.
Contato Institucional: Formulário integrado diretamente ao WhatsApp oficial da empresa.
